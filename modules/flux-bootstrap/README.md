# `modules/flux-bootstrap`

Bootstraps Flux CD into an existing Kubernetes cluster with a brand-new GitHub repo for the GitOps state. After this module runs, Flux is installed, its `flux-system` Kustomization is committed to the repo, and the cluster keeps its config in sync with everything pushed under `<flux_path>/`.

```
input: cluster_name, github_repo (+ optional flux_path, deploy_key_read_only)
    ↓
tls_private_key.flux                ← ECDSA P-256 key pair
    ↓
github_repository.flux              ← private repo, auto-initialised
    ↓
github_repository_deploy_key.flux   ← public key registered with write access
    ↓
flux_bootstrap_git.this             ← Flux installed into the cluster + manifests pushed
    ↓
output: private_key_pem (sensitive — for provider "flux" config),
        repository_url, repository_ssh_url, repository_full_name,
        flux_path, bootstrap_id
```

## Provider configuration (parent's responsibility)

This module **does not configure providers** — that has to happen at the parent. Two providers must be wired up:

```hcl
provider "github" {
  owner = var.github_owner
  token = var.github_token   # PAT with `repo` + `admin:public_key`
}

provider "flux" {
  kubernetes = {
    config_path = module.talos_cluster.kubeconfig_path
  }
  git = {
    url    = "ssh://git@github.com/${var.github_owner}/${var.github_repo}.git"
    branch = var.flux_branch
    ssh = {
      username    = "git"
      private_key = module.flux_bootstrap.private_key_pem
    }
  }
}
```

Note the chicken-and-egg: the provider needs `private_key_pem` from the module, and the module's `flux_bootstrap_git.this` needs the configured provider. Terraform handles this — the private key is generated by `tls_private_key` during apply, and provider configs resolve their references just before the resource that uses the provider runs.

## Usage

```hcl
module "flux_bootstrap" {
  source = "../../../modules/flux-bootstrap"

  cluster_name = var.cluster_name
  github_repo  = var.github_repo
  flux_branch  = var.flux_branch        # consumed by parent provider, not by the module
  flux_path    = var.flux_path          # null → clusters/<cluster_name>

  depends_on = [
    module.cilium,
    data.talos_cluster_health.this,
  ]
}
```
